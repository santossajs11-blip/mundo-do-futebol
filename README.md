# Mundo do Futebol

## Descrição
O Mundo do Futebol é um projeto desenvolvido no âmbito da unidade curricular UC00617.

Este site apresenta informações sobre o futebol, incluindo a sua história, principais regras e competições.

## Estrutura do projeto

- `index.html` — Página principal do projeto.
- `style.css` — Folha de estilos responsável pela apresentação visual.
- `README.md` — Documentação e informações sobre o projeto.
- `.gitignore` — Indica os ficheiros que devem ser ignorados pelo Git.
- `LICENSE` — Licença MIT do projeto.

## Como utilizar

1. Abrir o ficheiro `index.html` num navegador de Internet.
2. Utilizar o menu de navegação para consultar as diferentes secções.
3. Consultar a informação sobre história, regras e competições.
